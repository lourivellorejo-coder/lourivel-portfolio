# Lourivel A. Lorejo - Professional Portfolio

Professional portfolio for accounting, bookkeeping, executive or administrative support, and client service opportunities.

The downloadable workbooks use entirely fictional training data created for portfolio and QuickBooks practice. Company names, customers, vendors, employees, transactions, and results do not represent actual client work or relationships.

## GitHub Pages

1. Open **Settings > Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.

GitHub will display the public portfolio at the Pages URL shown in that settings screen.
